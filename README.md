## 📋 О проекте

**Repair Crew Lab** — это веб-приложение для кредитования строительных и ремонтных проектов, ориентированное на студентов и молодых специалистов.

### Основные возможности:
- 🔐 Регистрация и авторизация пользователей
- 💰 Кредитный калькулятор (ставка от 3.9% годовых)
- 📝 Отправка заявок на кредит
- 📊 История заявок с отслеживанием статуса
- 📞 Форма обратной связи

## 🛠 Технологический стек

### Frontend
- **HTML5** - семантическая вёрстка
- **CSS3** - кастомные стили + адаптив
- **JavaScript (ES6+)** - SPA логика, fetch API
- **Bootstrap 5** - адаптивная сетка, компоненты
- **Font Awesome** - иконки

### Backend (реализовано командой)
- **Framework** - Flask
- **Чистые SQL** - запросы (без ORM)

### Database (реализовано командой)
- MySQL
- 3+ связанных сущностей
